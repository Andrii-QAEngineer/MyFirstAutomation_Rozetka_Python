#Автоматизація тестування сайту Rozetka (Python + Selenium)

## Автоматизоване тестування сайту Rozetka за допомогою Python та Selenium

Цей проєкт присвячено розробці UI-автотестів для вебсайту Rozetka. У коді продемонстровано базові архітектурні підходи для створення стабільних та стійких до відмов відновлювальних тестових сценаріїв.

## Технологічний стек
- Мова програмування: Python 3.14
- Тестовий фреймворк: unittest
- Інструмент автоматизації: Selenium WebDriver 4.49.0
- Браузер: Mozilla Firefox
- Середовище розробки: Windsurf

## Інженерні рішення у коді
Для підвищення стабільності тестового сценарію було впроваджено такі підходи:
1. Маскування WebDriver. Налаштовано кастомний User-Agent для запобігання блокуванням з боку захисних систем вебсайту.
2. Явні очікування. Замість фіксованих пауз використано класи WebDriverWait та expected_conditions, що оптимізує час виконання тесту.
3. Обробка винятків. Кожен крок виконання загорнуто у конструкції try-except із логуванням інформативних повідомлень про помилки.
4. Автоматичне створення скріншотів. У разі виникнення збоїв на будь-якому етапі, метод save_screenshot автоматично зберігає знімок екрана у форматі png для подальшого аналізу.

## Опис тест-сценаріїв
1. Негативна перевірка форми авторизації на головній сторінці: перехід на головну сторінку, клік на кнопку входу через JavaScript, введення невалідних даних 1234567890, відправка форми та перевірка появи тексту повідомлення про помилку валідації.
2. Е2Е-сценарій купівлі ноутбука: покроковий перехід через категорії каталогу, додавання першого товару в кошик та перехід на сторінку оформлення замовлення.

## Інструкція для локального запуску
1. Склонуйте цей репозиторій до себе на комп'ютер:
git clone https://github.com

2. Переконайтеся в наявності встановленої бібліотеки Selenium:
pip install selenium

3. Запустіть скрипти тестів через командний рядок:
python test_rozetka_positive.py
python test_rozetka_negative.py
